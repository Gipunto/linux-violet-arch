Linux-violet custom kernel and modules with BORE scheduler and some other responsiveness/gaming optimizations. This is a PKGBUILD repo temporarily hosted on Github until AUR registrations open.

Linux-violet kernel featuring:
 - Arch Linux mainline patches
 - BORE scheduler
 - 1000HZ Tickrate
 - CONFIG_NO_HZ_FULL set to y
 - CONFIG_PREEMPT set to y
 - CONFIG_NTSYNC set to y
